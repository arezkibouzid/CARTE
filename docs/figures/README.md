# docs/figures

## Overview

Figures used by `docs/COA-Net_methodology.md` and `README.md`, plus the script that regenerates them. `make_figures.py` draws the architecture and incident-loop diagrams as SVG. It also runs the synthetic demo to draw the network maps and the COA chart. If given the markdown output of `coa-net bench`, it adds the benchmark chart.

## Interface

- `make_figures.py:main(argv=None)` is the CLI entry point. It takes:
  - `--out`: the output folder, default the script's own folder (`Path(__file__).parent`, i.e. `docs/figures`). It is created if missing.
  - `--bench`: the markdown written by `coa-net bench --out`. When given, the script adds `benchmark`.
  - `--only`: comma-separated figure names to build, for example `coa-net-architecture`. When only the architecture or the benchmark is asked for, the demo is not run.
  - `--html-only`: writes the HTML pages and does not render PNGs.
- `make_figures.py:architecture()` and `make_figures.py:incident_loop(timings=None)` return the diagram SVGs. Since 3 Nov 2026 the architecture diagram shows documents as inputs: a shared document intake feeds S1 (the doctrine set, compiled once at the event) and S2 (order understanding and the sketch reader with L9), and the readback sends an itineraries task to the exercise solver and a movement task to movement planning (S3 to S9). Its subtitle and legend say that every model role runs on an open model served locally. `Canvas.box` takes up to three sub-lines (`sub`, `sub2`, `sub3`).
- `make_figures.py:demo_figures()` builds the demo maps and the COA chart by running `COANet.from_graph(synthetic_theatre(0).G, sim_reps=50)`.
- `make_figures.py:parse_bench(md)` returns `(n, rows)` from the first table of the `coa-net bench` output. `make_figures.py:bench_chart(md)` draws it.
- `make_figures.py:Canvas` is a small SVG builder. `page(svg, width)` and `captioned(title, svg)` wrap SVGs in HTML.
- Generated files: `benchmark.png`, `coa-chart.png`, `coa-net-architecture.png`, `demo-network-before.png`, `demo-network-after-I1.png`, `demo-network-after-I2.png`, `incident-loop.png`, `road-movement-graph.png`, `survivability.png`.
- `real/` is not generated by this script: it holds JPEG copies, reduced in size, of the maps written by `coa-net exercise` on the organisers' Scenario 1 data (`exercise1-itineraries.jpg` from `map_itineraries.png`, `exercise1-difficult-areas.jpg` from `map_difficult_areas.png`), used by `docs/real_data_validation.md` and the root README. The third image, `exercise1-sharpest-turns.jpg` (the sharpest turn of each itinerary drawn on the scan, `docs/real_data_validation.md` section 4), is not a map `coa-net exercise` writes; it was made separately.

## Invariants

- Diagram colour code: blue boxes are language-model steps, grey boxes are symbolic steps, dashed boxes are inputs [make_figures.py module docstring; `BLUE`, `GREY`].
- The demo figures use the synthetic theatre with seed 0, so they are reproducible [make_figures.py:demo_figures].
- PNG rendering is optional. Without the `playwright` package, only the HTML pages are written and a notice is printed to stderr [make_figures.py:main].

## Side Effects

- Writes one HTML page per figure into `--out`. With `playwright` and Chromium installed, it renders the matching PNG at scale 1.5 and deletes the HTML page [make_figures.py:main]. Without the Python package, the `--html-only` page can be rendered by any headless browser at the same scale; the architecture PNG of 3 Nov 2026 was rendered that way, with Node Playwright (2100 × 1905 pixels).
- Creates `--out` if it does not exist (`mkdir(parents=True, exist_ok=True)`) and overwrites any existing `<name>.html` / `<name>.png` there, so a run with the default `--out` replaces the committed PNGs [make_figures.py:main].
- Prints to stdout: with `--html-only`, the full paths of the HTML pages; with `playwright`, the `<name>.png` names. Without `playwright` (and without `--html-only`), it prints only the notice on stderr [make_figures.py:main].
- Reads the `--bench` markdown file when given [make_figures.py:main].
- Imports `coa_net` (`baselines`, `parsing`, `pipeline`, `refine`, `render`, `scenarios`) and runs a full plan and refinement in memory [make_figures.py:demo_figures].

## Verification

No pytest test covers this script (`tests/` does not import it); verify by running it.

- Run (safe, no PNG overwrite): `python docs/figures/make_figures.py --out /tmp/figs --html-only`
- Run (regenerates the committed PNGs): `python docs/figures/make_figures.py --out docs/figures`
- Run (architecture only, no demo): `python docs/figures/make_figures.py --only coa-net-architecture`
